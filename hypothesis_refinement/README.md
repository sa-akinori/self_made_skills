# Hypothesis Refinement Skill

ユーザーが提示した仮説に対して、文献・特許調査を行い、新規性の評価・弱点の特定・洗練の提案を自動生成するスキルです。

## 機能概要

| 機能 | 説明 |
|------|------|
| 仮説の構造化 | 仮説を対象・メカニズム・予測・前提条件・適用範囲に分解 |
| 文献調査 | Google Scholar, PubMed, arXiv, J-STAGE 等から関連文献を検索 |
| 特許調査 | Google Patents, J-PlatPat 等から関連特許を検索 |
| 新規性評価 | 5段階スコアで仮説の新規性を評価 |
| 弱点分析 | 論理的整合性、エビデンス不足、交絡因子など7観点で分析 |
| 修正案の提示 | 仮説の修正版を根拠とともに提案 |
| 代替仮説の提案 | 異なるアプローチの代替仮説を2-3個提案 |
| 検証戦略の提案 | 仮説を検証するための研究デザインを提案 |

## ファイル構成

```
hypothesis_refinement/
├── README.md              # このファイル（使い方の説明）
├── skill.md               # スキル本体（実行プロンプト）
└── report_template.md     # 出力レポートのテンプレート
```

## 使い方

### 1. 仮説ファイルの作成

プロジェクトルートに `hypothesis.md` を作成し、検証したい仮説を記載してください。

```bash
# 例
cat > hypothesis.md << 'EOF'
仮説: 腸内細菌叢の多様性が睡眠の質に直接的な因果関係を持つ

背景:
- 近年の研究で腸脳相関が注目されている
- 睡眠障害患者の腸内細菌叢に特徴的なパターンが報告されている

想定メカニズム:
  腸内細菌 → 短鎖脂肪酸 → 迷走神経 → 脳幹睡眠中枢
EOF
```

テキストだけでなく、以下のような内容も自由に含められます:
- 図表・ASCIIアート
- 背景情報や関連データ
- 想定メカニズムのフロー
- 参考にしている先行研究

### 2. スキルの実行

#### Claude Code での利用（推奨）

```
/hypothesis-refinement
```

`hypothesis.md` が見つからない場合は、作成を促すメッセージが表示されます。

#### 直接利用

Claude との会話で `skill.md` の内容をシステムプロンプトまたはコンテキストとして渡してください。

## 出力例

スキルは以下のセクションを含む構造化レポートを生成します:

1. **エグゼクティブサマリー** - 調査全体の要約
2. **仮説の構造化** - 仮説の要素分解
3. **文献調査の結果** - 関連文献の一覧と要約
4. **特許調査の結果** - 関連特許の一覧と要約
5. **新規性の評価** - 5段階スコアと根拠
6. **弱点・不足の分析** - 7観点からの弱点分析
7. **洗練のための提案** - 修正案・代替仮説・検証戦略
8. **参考文献一覧** - 全引用のリスト

## 対応分野

分野を問わず使用できます:

- 自然科学（生物学、化学、物理学等）
- 医学・薬学
- 工学・情報科学
- 社会科学（心理学、経済学等）
- 人文科学

仮説の分野に応じて、調査対象のデータベースや評価基準が自動的に調整されます。

## 注意事項

- AI による調査に基づいて生成されるため、学術的な意思決定の際は専門家のレビューを推奨します
- Web 検索の結果に依存するため、アクセスできないデータベースの文献は取得できない場合があります
- 特許調査は主要な公開特許データベースを対象としており、非公開の出願は含まれません
